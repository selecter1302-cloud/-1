## 표정 설정 개편

- 상대별 구분을 없앴습니다. 주인공과 라이벌 모두 같은 관계이면 같은 집합을 사용합니다. 비밀·공개 연인은 ‘연인’으로 통합하고 타인·친구 등 다른 관계는 유지합니다. 작은 버튼에는 현재 관계를 표시합니다.
- 완전 삭제는 해당 캐릭터·화면의 모든 관계·행동에서 해당 표정을 차단합니다. 게임 출력, 강제 고정, 원본 복귀, 랜덤 선택, 집합, 미리보기에서도 우선 적용합니다. 삭제한 표정은 이름만 표시하는 복원 메뉴에서 되돌립니다. 복원해도 기존 집합에 자동으로 다시 추가하지 않습니다.
- 순간별 집합 → 실제 행동별 집합 → 기본 집합 → 원본 표정별 교체 순서로 적용합니다. 대사 해시·기분·장소 때문에 같은 행동이 자동으로 새 집합으로 갈라지지 않습니다. 절정 직전과 순간은 독립 설정입니다.
- 새 집합에는 원래 표정을 자동 포함하지 않습니다. ‘원래 표정 사용’을 직접 선택할 수 있습니다. 선택한 후보가 모두 차단되거나 OFF이면 원본으로 몰래 돌아가지 않고 해당 그림을 표시하지 않습니다. 사용 가능한 표정을 다시 선택하면 표시됩니다.
- 기본·추가 표정을 모두 볼 수 있는 두 열의 큰 얼굴 목록과 터치 확대를 제공합니다. 인물 전체 그림이던 다인 장면도 얼굴을 중심으로 표시합니다.
- 편집 시 게임 전체를 다시 갱신하지 않고 표정만 갱신합니다. 미리보기 선택으로 목록을 재생성하지 않습니다. 공유 축소 이미지 캐시·큰 미리보기 해제·순환 기록 상한을 적용하고 닫힌 화면의 스크롤 입력 참조를 정리했습니다.

## 기존 설정 이전

첫 실행에 기존 상대·연인 구분과 대사 기반 집합을 변환합니다. 중복 선택은 합치고, 예전 편집기가 섞어 넣었던 ‘원래 표정’은 대체 후보가 있는 집합에서 제거합니다. 기존 제외 설정은 삭제 차단으로 옮깁니다. 별도로 지정했던 기분·장소 등 조건은 보존합니다. 행동을 확실히 알 수 없는 옛 분기는 원본 표정별 교체로 보존합니다.

원본 설정 파일을 기기 안의 `mod_expression_filters.cfg.before-expression-v3`에 보관하고, 원본 집합·프로필과 변환 결과도 현재 설정 파일의 migration 절에 보관합니다. 업로드된 42개 집합은 누락 없이 검토되어 중복 15개를 합친 27개가 되었습니다. 개인 세이브·개인 설정은 APK나 배포에 포함하지 않습니다.
