ZIP을 풀어 `Narana-Edition-0.14.3.apk`를 설치하세요. **기존 나라나 앱을 삭제하지 말고 업데이트 설치하세요.**

기존 나라나 앱과 동일한 패키지 `org.selecter1302.gensokyomod`와 서명 인증서를 사용합니다. versionCode 48 (0.14.2는 47), Android 7.0 이상 / ARM64용입니다.

## 변경 사항

- 시작 설정의 라이벌 강함·크기·속도 화살표 버튼이 실제 값을 변경하도록 수정. 해당 세 항목은 업적 없이 변경할 수 있습니다.
- MOD 표정 집합에 ‘절정 직전’ 전용 행과 조건을 추가. ‘절정 순간’ 및 기존 행동별 설정과 별도로 편집할 수 있습니다.
- 함께 자기 명령에서 다음 날 CG 대상자를 보존하고 날짜 안내 뒤 CG를 표시하도록 수정. 자동 아침 이벤트가 열려도 CG가 가려지지 않습니다.
- 새 게임의 아침 기상 CG 기본값을 켰습니다. 기존 세이브도 최초 로딩 때 한 번 켜지며, 그 뒤 직접 끈 값은 저장·복원됩니다.
- **설정 → 세이브 → 모든 게임 세이브 삭제** 추가. 확인 후 일반·퀵·자동 저장 및 내부 게임 저장 백업을 삭제합니다. 도전과제·해금·게임 및 MOD 설정은 보존합니다. 현재 플레이와 외부에 내보낸 ZIP은 유지합니다.
- 0.14.2의 당일 밤 문 규칙, 한국어 고정 및 표시 명칭 수정도 포함합니다.

‘진심의 그녀’는 상대 선택과 행동 판단을 강화하는 AI입니다. ‘누나 왔다!’의 행동 연동 기능은 유료 행동당 라이벌 행동 기회를 주는 스케줄 설정입니다. 둘 다 켜면 진심 쪽 스케줄을 사용합니다. 진심을 끄면 이전 성격·행동성을 복원하고, 누나 왔다!가 켜져 있으면 행동 연동, 꺼져 있으면 기본 스케줄로 돌아갑니다. 이미 생긴 관계·사건 결과와 별도 신체 설정은 되돌리지 않습니다.

최종 리소스의 기능·메뉴·회귀 검사 175개, 실제 화면 렌더링 12개, NPC 시뮬레이션 144틱을 통과했습니다. 세이브 삭제는 격리된 시험 프로필에서 확인했으며 설정 파일과 내부 백업의 설정 바이트 보존을 검사했습니다. 원본 인증서 일치, v2/v3 서명, 정렬, APK 및 ZIP 무결성을 확인했습니다. 실제 Android 기기 설치와 터치 조작은 미검증입니다.

ZIP은 일반 Git의 100MiB 제한보다 커서 Git LFS로 올립니다. 배포 브랜치 최상위에 실제 ZIP을 두었고 소스·서명키·비밀번호는 포함하지 않습니다. `SHA256SUMS.txt`로 ZIP과 APK를 검증할 수 있습니다.
