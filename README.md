## 변경 사항

- **아침 기상 CG**: 중앙 인물·배경 칸 전체를 빈틈없이 채웁니다. 사용자가 선택한 방식대로 그림 전체를 칸 크기에 맞춰 늘리며, 자르거나 여백을 두지 않습니다. 날짜·장소·중앙 선택지까지 CG가 덮습니다. 좌우 패널과 하단 로그는 CG 영역 밖에 유지합니다.
- CG는 약 5초 표시한 뒤 자동으로 사라집니다. 선택지가 떠 있어도 기다리지 않습니다. CG를 눌러 먼저 닫을 수도 있으며, 가려진 버튼은 그 탭으로 작동하지 않습니다.
- **라이벌과 대결**: 기존 기본 3라운드에서 각자 1회씩 진행한 뒤 히로인이 판단하도록 변경했습니다. 원래 점수와 호감·성향에 따른 판정은 유지합니다. 구버전의 다회 설정도 1회로 적용합니다. 진행 중인 구버전 대결에 양쪽 기록이 이미 있으면 각자의 첫 기록으로 판정하며 새 차례를 반복하지 않습니다.
- 0.14.3의 시작 설정 수정, 독립 표정 분기, 세이브만 전체 삭제, 기존 CG·한국어·문 규칙 수정도 포함합니다.

최종 게임 리소스로 기능·메뉴·회귀 검사 171개, NPC 시뮬레이션 144틱, 실제 화면 렌더링 31개를 통과했습니다. 실제 동침 명령, 날짜 안내 뒤 CG 표시, 중앙 칸 전체/모서리 채움, 날짜·장소·선택지 가림, 선택지 대기 중 자동 종료, 숨겨진 버튼 입력 차단, 자동 아침 장면과 넓은 화면 배치를 검사했습니다. 대결은 양쪽 신청 경로, 중복 기록 차단, 두 차례 뒤 단 한 번의 판정, 구버전 저장 상태를 확인했습니다.
