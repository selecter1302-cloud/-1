# PCK Port 0.14.1 r1 — Android test build

Download and unzip `PCK-Port-0.14.1-r1.zip` to obtain the signed APK.
The ZIP is stored using Git LFS because it exceeds GitHub's normal Git file-size limit.

This is a separate-package test build (`org.selecter1302.gensokyomod.pckport`), so it does not replace the existing app or share its saves automatically. Android 7.0+ / ARM64 is required.

The requested PCK features are available in new-game MOD settings and in-game MOD → PCK 이식 기능. Headless functional/UI checks and APK signature/alignment verification passed. Physical Android installation and touch interaction have not been verified.

This deployment branch contains distribution files only; development source and signing keys are excluded. See SHA256SUMS.txt for ZIP and extracted APK checksums.
